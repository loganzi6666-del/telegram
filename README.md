# tgdl — 텔레그램 동영상 다운로더

텔레그램 동영상 링크를 **붙여넣거나 복사하기만 하면** 자동으로 내려받습니다.
내 계정이 가입해 있는 **비공개 채널·비공개 그룹**도 받을 수 있습니다.

- 링크를 붙여넣는 즉시 다운로드 시작 (대화형 모드)
- **클립보드 자동 감지**: 텔레그램에서 '링크 복사'만 누르면 자동 다운로드
- **창(GUI) 모드**: 터미널이 익숙하지 않아도 사용 가능
- **밖에서 휴대폰만으로**: 텔레그램 대화방에 링크를 붙여넣으면 집 컴퓨터가 받아
  다시 휴대폰으로 보내줍니다 (아이폰·안드로이드 모두 동일)
- **같은 와이파이 전송**: 받은 파일을 휴대폰 브라우저로 바로 내려받기
- **휴대폰에서 직접 실행**: 컴퓨터 없이 안드로이드(Termux)·아이폰(a-Shell)에서 실행
- **원격 조종**: 텔레그램 메시지로 **자동매매 봇을 켜고 끄고**, 컴퓨터를
  절전·종료하고, 항상 켜진 보조기기를 통해 **다시 켤 수도** 있습니다 (방법 8)
- **여러 연결로 동시에 받아 빠릅니다** (텔레그램은 연결 1개당 속도를 제한합니다)
- 이어받기(중간에 끊겨도 이어서), 중복 파일 자동 건너뛰기, 실시간 진행률 표시
- 앨범(여러 개 묶음), 메시지 범위, 포럼 토픽, 댓글, 초대 링크 지원

---

## 1. 설치

파이썬 3.9 이상이 필요합니다.

```bash
git clone https://github.com/loganzi6666-del/telegram.git
cd telegram
python -m pip install -r requirements.txt          # 필수 (telethon)
python -m pip install -r requirements-extra.txt    # 선택: 속도 향상 + 클립보드 (컴퓨터에서만)
```

### 업데이트

git 으로 받았으면 한 줄로 갱신됩니다.

```bash
python -m tgdl update
```

바뀐 내용을 보여주고, 필요한 모듈도 맞춰 설치합니다.
(`git pull` 을 직접 해도 됩니다. 갱신할 게 없으면 "이미 최신입니다" 라고만 나옵니다.)

> `requirements-extra.txt` 의 `cryptg` 는 다운로드 속도를 몇 배 높여줍니다.
> 단, **휴대폰(Termux / a-Shell)에서는 설치하지 마세요** — C 컴파일러가 필요해
> 실패합니다. 없어도 프로그램은 정상 동작합니다.

## 2. 텔레그램 API 키 발급 (최초 1회)

1. <https://my.telegram.org> 접속 → 본인 전화번호로 로그인
2. **API development tools** 클릭
3. App title / Short name 을 아무 이름으로 채우고 생성
4. 화면에 나오는 **api_id**(숫자)와 **api_hash**(문자열)를 저장

```bash
python -m tgdl config      # api_id / api_hash / 저장 폴더 입력
```

환경변수로 넣어도 됩니다: `TGDL_API_ID`, `TGDL_API_HASH`, `TGDL_DOWNLOAD_DIR`

## 3. 로그인 (최초 1회)

```bash
python -m tgdl login
```

전화번호(`+821012345678` 처럼 국가번호 포함) → 텔레그램 앱으로 받은 인증코드 →
(2단계 인증을 켜둔 경우) 비밀번호를 입력하면 끝입니다.
세션은 `~/.tgdl/session/` 에 저장되어 다음부터는 다시 묻지 않습니다.

## 4. 사용법

### 방법 1 — 링크 붙여넣기 (기본)

```bash
python -m tgdl
```

```
텔레그램 동영상 다운로더 (tgdl 1.0.0)
  · 링크를 붙여넣고 Enter 를 누르면 바로 다운로드가 시작됩니다.
  · 한 줄에 여러 링크를 붙여넣어도 됩니다.
  · 종료: q + Enter (또는 Ctrl+C)

https://t.me/c/1234567890/56          ← 여기에 붙여넣고 Enter
  20260203_56_영상.mp4  12.4MB/48.0MB   25.8%  3.1MB/s  남은시간 00:11
✔ 완료: /home/me/Downloads/telegram/내 채널/20260203_56_영상.mp4
```

### 방법 2 — 클립보드 자동 감지

```bash
python -m tgdl watch
```

실행해두고 텔레그램에서 동영상 메시지 → **링크 복사**만 누르면 자동으로 받습니다.
여러 개를 연달아 복사해도 순서대로 처리합니다. 종료는 `Ctrl+C`.

### 방법 3 — 창(GUI) 모드

```bash
python -m tgdl gui
```

링크 입력창, 클립보드 자동 감지 체크박스, 저장 폴더 선택, 진행률 표시가 있는
간단한 창이 열립니다. (리눅스에서 창이 안 열리면 `sudo apt install python3-tk`)

### 방법 4 — 명령줄에 링크 직접 전달

```bash
python -m tgdl https://t.me/c/1234567890/56
python -m tgdl https://t.me/channel/12 https://t.me/channel/13
python -m tgdl --from-file links.txt          # 파일에 줄바꿈으로 적어두고 한꺼번에
```

### 방법 5 — 밖에서 휴대폰만으로 (아이폰·안드로이드 공통) ⭐

집 컴퓨터를 켜둔 채로 실행해 둡니다.

```bash
python -m tgdl listen
```

그러면 밖에서 **휴대폰 텔레그램만으로** 받을 수 있습니다.
기종과 상관없습니다 — 아이폰, 안드로이드, 태블릿, 다른 컴퓨터 모두 같은 방법입니다.

1. 휴대폰 텔레그램 → **저장한 메시지**(Saved Messages) 열기
2. 받고 싶은 동영상의 링크를 붙여넣고 전송
3. 집 컴퓨터가 알아서 받고, 진행 상황을 그 메시지에 계속 알려줍니다
   (`⬇️ 받는 중 42%` → `⬆️ 보내는 중 80%` → `✅ 완료`)
4. 도착한 영상을 꾹 눌러 저장
   - **아이폰**: '동영상 저장' → 사진 앱
   - **안드로이드**: '갤러리에 저장' (또는 다운로드 폴더)

```bash
python -m tgdl listen --chat @내봇전용채널   # 저장한 메시지 대신 다른 대화방 감시
python -m tgdl listen --no-send             # 컴퓨터에만 받고 되돌려 보내지 않기
python -m tgdl listen --catch-up            # 시작할 때 최근 메시지의 링크도 처리
python -m tgdl listen --debug               # 어떤 메시지가 들어오는지 보기
python -m tgdl listen --poll 30             # 대화방 직접 확인 간격(초), 0 이면 끔
```

- 텔레그램 알림이 늦거나 오지 않는 경우가 있어, **15초마다 대화방을 직접
  확인**하는 안전망이 함께 돌아갑니다. 그래서 알림이 안 와도 링크를 놓치지
  않습니다(조금 늦게 시작될 뿐입니다).
- 시작 전에 이미 보내둔 링크는 건드리지 않습니다. 그것까지 받으려면
  `--catch-up` 을 붙이세요.
- 반응이 없으면 `--debug` 로 실행해 보세요. 메시지가 들어오는지, 대화방
  번호가 맞는지 화면에 표시됩니다.

- **왜 BotFather 봇이 아닌가요?** 봇은 파일을 **50MB 까지만** 보낼 수 있어서
  큰 동영상을 보낼 수 없습니다. 이 모드는 내 계정으로 직접 보내므로
  **최대 2GB**(텔레그램 프리미엄은 4GB)까지 가능합니다.
- 되돌려 보낼 때 **원본 해상도·재생시간을 그대로** 넘기므로 화면이 잘리지
  않습니다. 원본 정보를 알 수 없는 경우에만 파일 형태로 보냅니다(잘림 방지).
- 컴퓨터가 **켜져 있고 잠자기 상태가 아니어야** 합니다
  (윈도우: 설정 → 시스템 → 전원 → 절전 '안 함').
- 저장 폴더를 **iCloud Drive / 구글 드라이브 동기화 폴더**로 지정해두면
  (`python -m tgdl config`), 받은 파일이 휴대폰의 '파일'·드라이브 앱에도
  자동으로 나타납니다.

### 방법 6 — 같은 와이파이로 휴대폰에 옮기기

집에서 이미 받아둔 파일을 휴대폰으로 옮길 때 씁니다.

```bash
python -m tgdl serve
```

화면에 `http://192.168.0.5:8000` 같은 주소가 나옵니다. 휴대폰 브라우저
(아이폰은 사파리, 안드로이드는 크롬)에 그 주소를 입력하면 받은 파일 목록이
보이고, 이름을 누르면 휴대폰에 저장됩니다.

- **아이폰**: '파일' 앱에 저장 → 공유 → **비디오 저장** → 사진첩
- **안드로이드**: '다운로드' 폴더에 저장 (갤러리에서 바로 보입니다)

```bash
python -m tgdl serve --port 8080      # 포트 번호 바꾸기
```

> 실행 중에는 같은 와이파이의 다른 사람도 접속할 수 있으니, 다 옮겼으면
> `Ctrl+C` 로 꼭 닫아주세요.

### 방법 7 — 휴대폰에서 직접 실행 (컴퓨터 없이)

컴퓨터를 아예 쓰지 않고 휴대폰 안에서 프로그램을 돌립니다.

#### 🤖 안드로이드 (Termux) — 잘 됩니다

1. **F-Droid** 에서 **Termux** 설치 (<https://f-droid.org/packages/com.termux/>)
   구글 플레이의 Termux 는 업데이트가 중단돼 설치가 실패합니다. 꼭 F-Droid 버전으로.
2. Termux 를 열고 차례대로:

```bash
termux-setup-storage          # 저장 권한 허용 (팝업에서 '허용')
pkg update -y && pkg install -y python git
pip install telethon
git clone https://github.com/loganzi6666-del/telegram.git
cd telegram
python -m tgdl config         # api_id / api_hash 입력
python -m tgdl login          # 전화번호 + 인증코드
python -m tgdl                # 링크 붙여넣기 (길게 눌러 '붙여넣기')
```

- 받은 영상은 **`/sdcard/Download/telegram`** 에 저장되고 **갤러리에서 바로** 보입니다.
- 갤러리에 안 보이면 `pkg install -y termux-api` 를 한 번 설치해 두세요
  (다음부터 저장 직후 자동으로 갤러리에 반영됩니다).
- `cryptg` 는 설치하지 마세요(컴파일러가 필요해 실패합니다). 없어도 동작합니다.

#### 🍎 아이폰 (a-Shell) — 되지만 손이 더 갑니다

애플이 앱 밖에서 프로그램 실행을 막아두어, 터미널 앱을 거쳐야 합니다.

1. App Store 에서 **a-Shell** 설치 (무료)
2. a-Shell 을 열고:

```bash
pip install telethon
lg2 clone https://github.com/loganzi6666-del/telegram.git    # a-Shell 의 git
cd telegram
python -m tgdl config
python -m tgdl login
python -m tgdl
```

- `lg2 clone` 이 안 되면: 사파리로 ZIP 을 내려받아 **'파일' 앱**에서
  `a-Shell` 폴더로 옮기고, a-Shell 에서 `unzip 파일이름.zip` 하세요.
- 받은 영상은 **'파일' 앱 → a-Shell → Downloads/telegram** 에 있습니다.
  공유 → **비디오 저장** 을 누르면 사진 앱으로 들어갑니다.
- ⚠️ **a-Shell 화면을 켜둔 채로** 두세요. 다른 앱으로 넘어가면 iOS 가 다운로드를
  멈출 수 있습니다. 끊겼으면 같은 링크를 다시 넣으면 **이어받습니다**.
- 사진첩에 바로 저장하려면 유료 앱 **Pythonista 3** 를 쓰는 방법도 있습니다.

#### 두 기종 공통 주의

- 큰 영상은 데이터를 많이 씁니다. **와이파이**에서 받으세요.
- 휴대폰이 잠기면 느려지거나 멈출 수 있습니다. 화면을 켜두는 편이 안전합니다.
- 휴대폰에서 직접 받으면 중간 심부름꾼(컴퓨터)이 필요 없지만, 속도는
  컴퓨터보다 느립니다(`cryptg` 를 쓸 수 없어서).

### 방법 8 — 밖에서 자동매매 봇 켜고 끄기 · 컴퓨터 전원 ⭐

집 컴퓨터에서 이것을 켜 두면, 밖에서 **텔레그램 메시지 한 줄로** 자동매매 봇을
켜고 끄고 상태와 로그를 볼 수 있습니다.

```bash
python -m tgdl bot add "C:\매매봇\bot.py" --name 매매봇   # 한 번만 등록
python -m tgdl remote                                     # 대기 시작
python -m tgdl remote --power                             # 전원 명령까지 허용
```

휴대폰 텔레그램 → **저장한 메시지**(Saved Messages) 에 보내는 명령:

| 보낼 말 | 하는 일 |
| --- | --- |
| `/상태` | 봇이 돌고 있는지, 몇 시간째인지, 컴퓨터가 켜진 지 얼마나 됐는지 |
| `/시작` (`/on`) | 매매봇 켜기 — **이미 켜져 있으면 두 번 켜지 않습니다** |
| `/중지` (`/off`) | 매매봇 끄기 — Ctrl+C 와 같은 신호를 먼저 보내 정리할 시간을 줍니다 |
| `/재시작` | 껐다 다시 켜기 |
| `/로그` · `/로그 50` | 매매봇이 남긴 최근 기록 보기 |
| `/절전` | 컴퓨터를 절전으로 내리기 (깨우기가 가장 잘 됩니다) |
| `/종료` | 컴퓨터 완전히 끄기 |
| `/재부팅` · `/잠금` | 다시 시작 · 화면만 잠그기 |
| `/확인` · `/취소` | 전원 명령 확인 · 취소 |
| `/도움` | 명령 목록 |

다운로더와 함께 쓰려면 `python -m tgdl listen --control` 로 실행하세요. 같은
대화방에서 링크는 다운로드하고, `/` 명령은 원격 조종이 처리합니다.

**안전장치**

- 기본 감시 대상은 **'저장한 메시지'** — 나 혼자만 들어갈 수 있는 방입니다.
  다른 대화방(`--chat`)을 쓰더라도 **내 계정이 보낸 명령만** 실행합니다.
- **전원 명령은 기본으로 꺼져 있습니다.** `--power` 를 붙인 경우에만 됩니다.
- 전원 명령은 곧바로 실행하지 않고 **한 번 더 확인**을 받습니다. 그리고
  내리기 전에 **매매봇을 먼저 부드럽게 멈춥니다**(주문 정리할 시간을 줌).
- 매매봇을 두 개 띄우면 주문이 두 번 나가므로, `/시작` 은 이미 돌고 있으면
  **아무것도 하지 않습니다**.

**매매봇이 주문을 정리할 수 있게 하려면** — `/중지` 는 먼저 Ctrl+C 와 같은
신호를 보내고 `grace` 초(기본 20초)까지 기다린 뒤, 그래도 안 끝나면 종료 요청,
마지막에 강제 종료로 넘어갑니다. 봇 쪽에 이런 정리 코드를 넣어 두면 미체결
주문을 남기지 않습니다.

```python
try:
    거래_루프()
except KeyboardInterrupt:      # /중지 가 보내는 신호
    미체결_주문_취소()
    포지션_기록_저장()
```

정리에 더 긴 시간이 필요하면 `--grace 60` 처럼 늘리세요. 봇이 자체 종료 절차를
가지고 있다면 설정 파일의 `stop_command` 에 그 명령을 적어 두면 그것을 먼저
실행합니다.

**먼저 컴퓨터에서 시험해 보세요** (텔레그램 없이 같은 동작을 확인합니다):

```bash
python -m tgdl bot start      # 켜기
python -m tgdl bot status     # 상태
python -m tgdl bot log --lines 50
python -m tgdl bot stop       # 끄기
python -m tgdl bot list       # 등록된 프로그램 목록
```

봇이 남기는 화면 출력은 `~/.tgdl/logs/<이름>.log`(윈도우는
`C:\Users\<나>\.tgdl\logs\`)에 쌓이고, `/로그` 가 그 마지막 줄들을 보여줍니다.
`--cwd` 로 실행 폴더를, `--grace` 로 정리를 기다릴 시간(초)을 지정할 수 있습니다.

#### 컴퓨터가 꺼져 있어도 켜려면 (Wake-on-LAN)

**솔직한 한계**: 꺼진 컴퓨터는 어떤 프로그램도 돌릴 수 없으므로 **스스로는
켤 수 없습니다.** 랜카드만 약한 전기로 깨어 있어서, **같은 공유기 안에서**
특별한 신호(매직 패킷)를 받으면 본체를 깨웁니다. 그래서 집에 **항상 켜져 있는
작은 기기 하나**가 필요합니다.

보조기기로 쓸 수 있는 것: 라즈베리파이 · 안 쓰는 옛 안드로이드폰(Termux) ·
NAS · 항상 켜 두는 다른 컴퓨터.

**① 집 컴퓨터 준비 (윈도우, 한 번만)**

1. **유선 랜(이더넷)으로 연결**하세요. 와이파이는 깨우기가 대부분 안 됩니다.
2. 재부팅 → BIOS/UEFI 진입(보통 `Del` 또는 `F2`) → 전원 관련 항목에서
   **Wake on LAN** / `Power On By PCI-E` / `Resume By PCI-E Device` → **활성화**
3. 윈도우: `장치 관리자` → `네트워크 어댑터` → 유선 랜카드 → 속성
   - `전원 관리` 탭 → **'이 장치가 컴퓨터를 절전 모드에서 깨울 수 있음'** 체크
   - → **'Magic Packet 에서만 컴퓨터를 절전 모드에서 해제'** 체크
   - `고급` 탭 → `Wake on Magic Packet` = **사용**
4. 관리자 명령 프롬프트에서 **빠른 시작·최대 절전 끄기**:
   ```
   powercfg /h off
   ```
   윈도우의 '빠른 시작'은 종료를 절반쯤 최대 절전으로 만들어 깨우기를 막고,
   최대 절전이 켜져 있으면 `/절전` 이 절전 대신 최대 절전으로 들어갑니다.
5. 랜카드 주소(MAC)와 랜 IP 확인:
   ```
   ipconfig /all
   ```
   이더넷 항목의 **물리적 주소**(예: `A1-B2-C3-D4-E5-F6`)와
   **IPv4 주소**(예: `192.168.0.10`)를 적어 두세요. IP 는 공유기에서
   **고정 할당(DHCP 예약)** 해 두는 것이 좋습니다.

**② 보조기기에서 (항상 켜 둘 기기)**

```bash
pip install -r requirements.txt
python -m tgdl login                  # 같은 텔레그램 계정으로 로그인
python -m tgdl wake --mac A1-B2-C3-D4-E5-F6 --host 192.168.0.10 --save
python -m tgdl waker                  # `/깨우기` 를 기다린다
```

`wake` 는 지금 한 번 깨워 보는 시험용입니다. 잘 되면 `waker` 로 계속 켜 두세요.
이제 밖에서 **`/깨우기`** 만 보내면 집 컴퓨터가 켜지고, 켜졌는지까지 확인해
알려줍니다. 집 컴퓨터가 이미 켜져 있으면 보조기기는 **조용히 넘어가고** 집
컴퓨터가 직접 대답합니다(같은 명령에 두 번 답하지 않도록).

안드로이드를 보조기기로 쓸 때는 Termux 에서 `termux-wake-lock` 으로 잠들지
않게 하고, 충전기를 꽂아 두세요.

**③ 집 컴퓨터가 켜지면 자동으로 대기하게 하기 (작업 스케줄러)**

깨워도 `remote` 가 돌지 않으면 명령을 받을 수 없으니, 윈도우 시작 시 자동
실행으로 등록합니다.

1. `작업 스케줄러` 실행 → `작업 만들기`
2. `일반` 탭 → **'사용자가 로그온했는지 여부에 관계없이 실행'**,
   **'가장 높은 수준의 권한으로 실행'** 체크
3. `트리거` 탭 → 새로 만들기 → **'시작할 때'**
   (절전에서 깨어난 뒤에도 계속 돌게 하려면 로그온 트리거도 함께 추가)
4. `동작` 탭 → 프로그램 시작
   - 프로그램: `python.exe` 의 전체 경로 (`where python` 으로 확인)
   - 인수: `-m tgdl remote --power`
   - 시작 위치: 아무 폴더 (예: `C:\Users\<나>`)
5. `조건` 탭 → **'컴퓨터를 AC 전원으로 사용하는 경우에만 작업 시작'** 해제

> `pythonw.exe` 가 아니라 `python.exe` 를 쓰세요. 화면에는 똑같이 아무 창도
> 뜨지 않지만, `pythonw` 는 콘솔이 없어서 `/중지` 가 매매봇에 Ctrl+Break(=Ctrl+C)
> 를 보낼 수 없습니다. 그러면 부드럽게 멈추지 못하고 강제 종료로 넘어갑니다.

**대안 — 스마트 플러그**: 와이파이 콘센트로 전원을 넣고, BIOS 에서
`Restore on AC Power Loss = Power On` 으로 두면 전기가 들어올 때 자동으로
켜집니다. 데스크탑만 가능하고 노트북은 안 되며, 매매 중 갑작스러운 전원
차단은 위험하니 `/종료` 로 정상 종료한 뒤에만 쓰세요.

**권장 조합**: `/절전` 으로 내리고 `/깨우기` 로 깨우기. 완전 종료보다 깨우기가
훨씬 잘 되고, 복구도 몇 초면 끝납니다.

## 5. 지원하는 링크 형식

| 링크 | 의미 |
| --- | --- |
| `https://t.me/channel/123` | 공개 채널/그룹의 메시지 하나 |
| `https://t.me/c/1234567890/123` | **비공개** 채널의 메시지 하나 |
| `https://t.me/c/1234567890/45/123` | 비공개 포럼(토픽) 그룹의 메시지 |
| `https://t.me/channel/100-130` | 메시지 **범위** (100번부터 130번까지) |
| `https://t.me/channel/100,105,110` | 메시지 여러 개 |
| `https://t.me/channel/123?comment=456` | 채널 글에 달린 **댓글**의 동영상 |
| `https://t.me/+AbCdEfGh` , `t.me/joinchat/...` | **초대 링크** (가입 후 동영상 탐색) |
| `https://t.me/channel` | 번호가 없으면 최신 동영상을 훑어서 받음 (기본 200개) |
| `tg://resolve?domain=...&post=...` | 텔레그램 앱 내부 링크 |

앨범(한 번에 여러 개 올린 묶음) 링크를 넣으면 **묶음 전체**를 받습니다
(`--no-album` 으로 끌 수 있습니다).

## 6. 비공개 채널에 대해

- 비공개 채널 링크는 `https://t.me/c/...` 모양입니다. 텔레그램 앱에서 해당
  메시지를 길게 눌러 **링크 복사**를 하면 이 형태로 복사됩니다.
- **내 계정이 그 채널에 이미 가입되어 있어야 합니다.** 이 프로그램은 내 계정으로
  로그인해 내가 볼 수 있는 내용만 내려받습니다. 가입하지 않은 비공개 채널은
  텔레그램 서버가 접근을 거부하며, 프로그램도 받을 수 없습니다.
- 초대 링크(`t.me/+...`)를 넣으면 먼저 채널 가입을 시도한 뒤 동영상을 찾습니다.
  관리자 승인이 필요한 채널이면 승인 후 다시 실행하세요.
- 처음 비공개 채널을 받을 때는 대화 목록을 한 번 읽어옵니다(몇 초 걸립니다).

## 7. 옵션

| 옵션 | 설명 |
| --- | --- |
| `-o, --out <폴더>` | 저장 폴더 지정 |
| `-c, --concurrency <숫자>` | 동시에 받을 **파일** 수 (기본 2, 최대 8) |
| `--connections <숫자>` | 파일 하나에 쓸 **연결** 수 (기본 4, 최대 16). 속도에 가장 큰 영향 |
| `--all` | 동영상뿐 아니라 사진·문서 등 모든 첨부 받기 |
| `--overwrite` | 같은 파일이 있어도 다시 받기 |
| `--no-album` | 앨범의 다른 항목은 받지 않기 |
| `--flat` | 채널별 폴더를 만들지 않고 한 폴더에 저장 |
| `--limit <숫자>` | 번호 없는 링크에서 훑을 메시지 수 (기본 200) |
| `--from-file <파일>` | 링크 목록 파일에서 읽기 |
| `--proxy socks5://호스트:포트` | 프록시 사용 (`pip install python-socks[asyncio]`) |
| `--interval <초>` | 클립보드 확인 간격 (기본 1초) |
| `--chat <대화방>` | `listen`: 감시할 대화방 (기본 `me` = 저장한 메시지) |
| `--no-send` | `listen`: 받은 파일을 되돌려 보내지 않기 |
| `--catch-up [개수]` | `listen`: 시작할 때 최근 메시지에서 링크 찾기 (기본 20개) |
| `--poll <초>` | `listen`: 대화방 직접 확인 간격 (기본 15, `0` 이면 끔) |
| `--debug` | 어떤 메시지가 오는지 자세히 표시 |
| `--port <번호>` | `serve`: 휴대폰이 접속할 포트 번호 (기본 8000) |

기타 명령: `python -m tgdl config --show` (설정 보기), `python -m tgdl logout`
(로그인 세션 삭제), `python -m tgdl update` (최신 코드로 갱신), `python -m tgdl help`

### 원격 조종 관련 옵션

| 옵션 | 설명 |
| --- | --- |
| `remote --power` | 전원 명령(`/절전` `/종료` `/재부팅`) 허용 |
| `remote --chat @방이름` | '저장한 메시지' 대신 다른 대화방에서 명령 받기 |
| `listen --control` | 다운로드와 원격 조종을 한 번에 |
| `bot add <경로> --name 이름 --cwd 폴더 --grace 초` | 켜고 끌 프로그램 등록 |
| `bot start\|stop\|restart\|status\|log\|list\|remove` | 컴퓨터에서 직접 조작 |
| `wake --mac <주소> --host <IP> --save` | 지금 깨우기 + 설정 저장 |
| `waker --mac <주소> --host <IP>` | 보조기기에서 `/깨우기` 대기 |

설정 파일(`~/.tgdl/config.json`)을 직접 고쳐도 됩니다:

```json
{
  "programs": [
    {
      "name": "매매봇",
      "command": "C:\\매매봇\\bot.py",
      "cwd": "C:\\매매봇",
      "grace": 30,
      "stop_command": ""
    }
  ],
  "allow_power": true,
  "stop_bot_first": true,
  "wake_mac": "A1:B2:C3:D4:E5:F6",
  "wake_host": "192.168.0.10",
  "wake_port": 3389
}
```

`wake_port` 는 켜졌는지 확인할 때 붙어 볼 포트입니다(원격 데스크톱 `3389` 등).
`0` 이면 ping 으로 확인하는데, 윈도우 방화벽이 ping 을 막는 경우가 많으니
포트를 지정하는 편이 확실합니다.

## 8. 저장 방식

```
<저장폴더>/<채널 이름>/<날짜>_<메시지번호>_<원래 파일명>.mp4
```

- 다운로드 중에는 `....mp4.part` 로 저장되고 완료되면 이름이 바뀝니다.
  중간에 끊겨도 다시 실행하면 **그 지점부터 이어받습니다**.
- 같은 파일이 이미 있고 용량이 같으면 건너뜁니다.

## 9. 속도가 느릴 때

텔레그램은 **연결 하나당** 속도를 제한합니다. 그래서 이 프로그램은 파일 하나를
여러 조각으로 나눠 **여러 연결로 동시에** 받습니다(기본 4개).

### 연결 수 늘리기

```bash
python -m tgdl --connections 8 <링크>     # 8개 연결
python -m tgdl --connections 16 <링크>    # 최대
```

마음에 들면 기본값으로 저장하세요 — `~/.tgdl/config.json` 의 `connections` 값.

### 확인할 것들

| 확인 | 방법 |
| --- | --- |
| `cryptg` 가 깔려 있나? | `python -c "import cryptg; print(cryptg.__version__)"` — 없으면 암호 해독이 파이썬으로 처리돼 **1MB/s 아래로** 떨어집니다. `pip install cryptg` (컴퓨터에서만) |
| 연결 수 | `python -m tgdl config --show` 의 `연결 수`. 4 → 8 로 올려보세요 |
| 동시 파일 수 | 여러 파일을 한꺼번에 받으면 각 파일은 느려집니다. `-c 1` 로 하나씩 받으면 파일당 속도가 올라갑니다 |
| 와이파이/유선 | 휴대폰 테더링이나 약한 와이파이면 그쪽이 한계입니다 |
| 휴대폰에서 실행 중? | Termux·a-Shell 은 `cryptg` 를 쓸 수 없어 컴퓨터보다 느립니다 |

### 그래도 느리면

- 연결을 아무리 늘려도 인터넷 회선 속도를 넘을 수는 없습니다.
- 텔레그램이 계정별로 속도를 제한하는 경우도 있습니다(프리미엄은 더 빠릅니다).
- 연결을 너무 많이 열면 오히려 제한(`속도 제한 — N초 대기`)에 걸립니다.
  그럴 때는 연결 수를 줄이세요.

> 빠른 방식을 쓸 수 없는 파일(예: CDN 전송)은 자동으로 기본 방식으로 바뀝니다.
> `빠른 다운로드를 쓸 수 없어 기본 방식으로 받습니다` 라고 나오면 그 경우이며,
> 파일은 정상적으로 받아집니다.

## 10. 자주 겪는 문제

| 증상 | 해결 |
| --- | --- |
| `비공개 채널을 찾을 수 없습니다` | 로그인한 계정이 그 채널에 가입돼 있는지, 링크가 `t.me/c/...` 형태인지 확인 |
| `api_id / api_hash 가 올바르지 않습니다` | `python -m tgdl config` 로 다시 입력 |
| `동영상이 없습니다` | 사진·문서 메시지일 수 있습니다. `--all` 로 실행 |
| `속도 제한 — N초 대기` | 텔레그램의 정상적인 제한입니다. 자동으로 기다린 뒤 이어서 받습니다 |
| 클립보드 감시가 안 됨 | `pip install pyperclip` 또는 리눅스에서 `sudo apt install xclip` |
| 다운로드가 느림 | `pip install cryptg` 설치 여부 확인 |
| `listen` 이 반응이 없음 | ① 링크를 **새로** 보내보세요(시작 전 메시지는 건드리지 않습니다. `--catch-up` 으로 포함 가능) ② `--debug` 로 실행해 메시지가 들어오는지 확인 ③ 컴퓨터가 잠자기인지, 인터넷이 끊겼는지 확인 |
| `listen` 시작 알림이 안 옴 | 휴대폰에서 '저장한 메시지' 대화방을 열어 확인하세요. 화면에 `시작 알림을 보냈습니다` 가 떴다면 전송은 성공한 것입니다 |
| `용량이 너무 커서 보낼 수 없습니다` | 2GB 초과 파일입니다. 컴퓨터에는 저장돼 있으니 `serve` 나 iCloud 폴더로 옮기세요 |
| `/시작` 했는데 `바로 끝났습니다` | 매매봇 자체의 오류입니다. 함께 표시된 로그를 보세요. `--cwd` 로 실행 폴더를 지정해야 하는 경우가 많습니다(설정 파일·API 키를 못 찾음) |
| `/중지` 가 `강제로 끝냈습니다` 로 끝남 | 봇이 Ctrl+C 를 처리하지 않습니다. 봇에 `KeyboardInterrupt` 정리 코드를 넣거나 `--grace` 를 늘리세요 |
| `전원 명령이 꺼져 있습니다` | 집 컴퓨터에서 `python -m tgdl remote --power` 로 실행하세요 |
| `/절전` 인데 최대 절전으로 들어감 | 관리자 명령 프롬프트에서 `powercfg /h off` |
| `/깨우기` 했는데 안 켜짐 | ① 유선 랜인지 ② BIOS 의 Wake on LAN ③ 랜카드 `전원 관리` 설정 ④ `powercfg /h off` ⑤ 보조기기가 **같은 공유기**에 있는지 (외부 인터넷에서는 매직 패킷이 들어오지 않습니다) |
| 깨운 뒤 `/상태` 에 반응이 없음 | 윈도우 시작 시 `remote` 가 자동 실행되도록 작업 스케줄러에 등록했는지 확인 |
